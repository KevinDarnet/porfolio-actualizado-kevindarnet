# Kevin Darnet — Personal Portfolio (MERN & AppSec)

Portfolio profesional diseñado bajo estética **Minimalist Dark Technical UI** (inspirado en layouts editoriales modulares de Behance), desarrollado con **React**, **Tailwind CSS** e internacionalización reactiva (**ES / EN**).

## Características Principales
- **Estética Dark Mate & Modular**: Paleta `#0d0d0d` / `#121212` con tarjetas `#181818` / `#1e1e1e`, bordes redondeados (`rounded-3xl`), botones tipo píldora (`rounded-full`) y rutas técnicas en tipografía monospace (`JetBrains Mono` + `Inter`).
- **Internacionalización (i18n) Desacoplada**: Diccionarios completos en `src/locales/es.json` y `src/locales/en.json` gestionados mediante `LanguageContext` sin recargar la página.
- **Secciones Especializadas**:
  1. **Header + Switcher `[ ES | EN ]`**: Navegación fija con blur e identificador `k.darnet_`.
  2. **Hero Section**: Presentación *Full-Stack MERN Developer* + badge *Cybersecurity Student | AppSec Fundamentals*.
  3. **Servicios en Producción**: Diferenciación clara de sistemas activos en producción con indicador verde pulsante (`Active in Production`) y métricas de disponibilidad (`+99.9% Uptime | API Segura`).
  4. **Proyectos Destacados**: Grilla 2x2 con tags técnicos y enlaces directos a Demo y GitHub.
  5. **Stack Técnico & AppSec Fundamentals**: 4 módulos (Frontend, Backend, Base de Datos y Security & Best Practices alineado con JWT, bcrypt, sanitización NoSQL, CORS/.env y OWASP Top 10).
  6. **Trayectoria / Experiencia**: Tabla modular sobria de impacto técnico.
  7. **Contacto (`... /Contacts ...`)**: Disponibilidad activa, copiado rápido de correo y atribución limpia.

## Ejecución Local

```bash
npm install
npm run dev
```

Para compilar a producción:

```bash
npm run build
```
